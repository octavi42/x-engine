# the system of tools to start a startup

## velocity (shipped)

- daily X follower snapshot for 3,011 YC startups
- ranked by 7d/30d/90d growth
- first publishable leaderboard 2026-05-20

## x-engine (live)

- generates daily X drafts from sessions and commits
- auto-discovers projects from obsidian
- 6 format archetypes, satori-rendered image posts next

## northstar (live)

- scores raw ideas across 7 axes
- review_idea adversarial critic catches feature-vs-product risk
- top scored: cap-closure, descript-fuzz, honest-blast-radius

## autonomous-company-tool (sketch)

- observes how work flows inside a company
- maps it as a graph, scores autonomy-readiness per node
- wedge: the map, not the agent
