# System of Tools

- **Repo:** none (meta-project — the tools are the deliverables, this is the framing)
- **Description:** A system of small, single-purpose tools that each automate one founder-job (lead discovery, growth radar, post automation, idea scoring, autonomous-flow mapping). Stacked together, they form an operating system for starting a startup solo. Velocity is tool #1.
- **Stack:** N/A — each tool ships standalone with its own stack
- **Status:** active — Velocity (tool #1) shipped. ship-it CLI, x-engine, Northstar, autonomous-company-tool are in or near the system.
- **Content angles:**
  - Manifesto post — "the system of tools to start a startup. each one automates one founder-job. here's the map." (single post or thread)
  - Per-tool reveal — one post per tool when it ships, framed as "tool N of the system"
  - Composition story — when two tools chain (Velocity data → x-engine drafts → ship-it CLI posts), tell that flow
  - The wedge — why a solo founder needs *small tools*, not one mega-platform (compose-vs-monolith argument)
  - Tools-as-content — the tool launch IS the marketing artifact, no separate marketing site needed
  - What's missing from the system — public callouts for the next tool to build (idea sourcing from public lists?)
  - The Romania angle — building a startup OS from outside SF. Geographic positioning + cost-of-living arbitrage
