## 3. Technical tip — roadtosf Stripe NEXT_PUBLIC bake-at-build gotcha

> roadtosf live-mode Stripe gotcha: NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY is baked at build time
>
> if you swap test keys for live keys on Vercel and redeploy, the old key ships. fix: set the live key, uncheck "Use existing Build Cache", redeploy
>
> env vars run at build, not at boot

**Format:** bug-fix (cause → symptom → fix, single-tweet, with the build-cache sub-fix named)
**Type:** technical tip — roadtosf launch-day gotcha. Next.js bakes `NEXT_PUBLIC_*` env vars into the client bundle at build time, not at boot. On Vercel, swapping Stripe test keys for live keys in the environment-variables UI and clicking "Redeploy" reuses the cached build and ships the stale test key to the client, so Stripe.js initializes in test mode on a live page. Fix: set the live key in the right environment slot (Production), hit "Redeploy", AND explicitly uncheck "Use existing Build Cache" on the redeploy modal. Also verify after deploy by sniffing the bundle for the publishable key. General pattern: for any public build-time env var, treat a key swap as a cache-bust event, not a boot-time change.

## 5. Thread — Clio interpretation-science narration rules

### Hook (post 1)

> Clio's narrator is a model. the risk is not that it lies: it hedges when a plaque is clear and asserts when a source is thin. we rewrote the prompt around four interpretation-science rules. here's the shape

### Post 2 — One sentence theme

> 1/ one sentence theme. every narration chunk opens with a single sentence that names the specific story about this place. not a category, not a date range. the walker leaves with one thing they'd repeat at dinner

### Post 3 — People over dates

> 2/ people over dates. "built in 1887" is a plaque. "a widow fought the city for ten years to keep this block standing" is a story. the prompt forces a named actor and a verb in every chunk, not a year and a noun

### Post 4 — Pointable anchors

> 3/ pointable anchors. every claim names a thing the walker can see from where they stand. "look at the second-floor window" beats "the building has a notable facade". the map ring points at the same thing the voice does

### Post 5 — Hedge by source confidence

> 4/ hedge by source confidence. high-confidence facts land flat. low-confidence legends open with "locals say" or "one account claims". the hedge is in the first three words, not buried in a closing qualifier

### Post 6 — Payoff

> 5/ payoff. the narrator stops sounding like Wikipedia and starts sounding like a guide who knows which stories are solid and which are gossip. four rules, one prompt, every walk reads differently
