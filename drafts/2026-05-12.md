## 5. Thread — Day 12 of roadtosf in prod, four small bugs that each cost real money

### Hook (post 1)

> launched roadtosf 4/30 for ElevenLabs Hackathon #5. 12 days running it in prod
> 
> four small bugs that each cost real money. one was OpenAI bills, one was Resend deliverability, one was Stripe build-cache, one was Stripe descriptor

### Post 2 — OpenAI image-regen bill

> base64 image dataUrls in sessionStorage = ~$0.30/refresh in OpenAI image regen
> 
> partialize stripped imageUrl on rehydrate. page reload saw no image, refetched
> 
> fix: vercel blob put, return short url, drop dataUrl from the result type

### Post 3 — Resend deliverability

> Resend default sender onboarding@resend.dev only delivers to the account owner
> 
> launch day: every visitor got 403 on OTP. I got my own welcome email fine
> 
> fix: verify the domain in Resend, set RESEND_FROM, redeploy

### Post 4 — Stripe NEXT_PUBLIC build cache

> NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY bakes at build time on Vercel
> 
> swap test keys for live keys, redeploy, and the old test pk_test_ still ships if Use Existing Build Cache is on
> 
> uncheck the cache. redeploy. only then does the live key reach the browser

### Post 5 — Stripe statement descriptor

> Stripe statement descriptor is ROADTOSF. short brand. no phone number
> 
> a phone number implies staffed support I don't have. cards that show ROADTOSF look legit. cards with a random LLC + 800 number get disputed
> 
> recognition prevents the chargeback before it starts
