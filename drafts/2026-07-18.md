## 5. Thread — 4 architectural forks before shipping an autonomous-company observer

### Hook (post 1)

> before shipping an autonomous-company observer, we hit 4 architectural forks
> 
> none had obvious answers. all four break the tool if you get them wrong
> 
> metadata as personal data. handoff causality. node granularity. readiness scoring

### Post 2 — metadata is personal data

> 1. metadata is personal data
> 
> GDPR DPIA + purpose limitation from day one, not a retrofit
> 
> calendar attendees, doc edit histories, Slack audit logs. all identifiable. treat like content, log like content, delete like content

### Post 3 — handoff causality

> 2. handoff edges need a causality proxy
> 
> bare temporal correlation lies. actor A wrote 5 min before actor B did. that isn't a handoff, that's coincidence
> 
> require an artifact reference. same doc id, same ticket id. no shared artifact, no edge. call it the honesty tax

### Post 4 — node granularity

> 3. node granularity breaks the map
> 
> 5-minute windows collapse legit sequential actions. 1-minute inflates noise. we settled on 5 for scaffolding, drilled to 1 only for top-3 flows
> 
> granularity isn't a global constant. it's a per-flow decision

### Post 5 — three-bucket readiness

> 4. three-bucket readiness (A/B/C), not 0.0 to 1.0 floats
> 
> fake precision dies in the falsifier. what's the difference between 0.62 and 0.65? nothing you can defend to a CFO
> 
> three buckets survive. everything else backfits

### Post 6 — where it lands

> where it lands: invoice approval routing
> 
> explicit handoffs, no causality inference needed. CFO-legible ROI, no telemetry retrofit
> 
> sell the ranked map, not the automation. flip the Sierra/Decagon pitch
