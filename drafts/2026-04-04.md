### Thread outline:
1. Hook (above)
2. What shipped: four model sizes under Apache 2.0, multimodal (text, images, audio), forward-compatible with Gemini Nano 4
3. Why mobile devs care: no API calls, no latency, no per-token cost — the model lives on the device
4. The Clio angle: location-based AI narration could run offline if on-device models handle summarization well enough
5. What still breaks: on-device can't match cloud for complex reasoning — real architecture is hybrid with cloud fallback
6. Prediction: by end of 2026, most mobile AI apps default to on-device with cloud fallback, not the other way around
