## 3. Technical tip — Clio Step inside Resend-after-route 5s deadline

> Clio Step inside place-request path: a naive handler awaits Resend inside the POST and ships the email latency to the user
>
> fix: run Resend AFTER the route answers, with a 5s deadline. no RESEND_API_KEY means email is off. the user pays zero
>
> fire-and-watch beats fire-and-wait

**Format:** bug-fix (cause → symptom → fix, single-tweet, with the key-off degradation path named)
**Type:** technical tip — Clio's Step inside "request a place" endpoint stores the typed place server-side AND emails the Clio team through Resend. The simple shape awaits `resend.send()` inside the POST handler, which pins the user's HTTP 200 to Resend's response time. Fix: respond to the client first, then run Resend AFTER the route returns, with a hard 5s deadline (`RESEND_API_KEY`, `STEP_INSIDE_REQUEST_EMAIL`, `STEP_INSIDE_REQUEST_FROM`). If the API key is missing, email is off and the request still logs. The user pays zero email-send latency and the server degrades gracefully.
