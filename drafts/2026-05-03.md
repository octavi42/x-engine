### Post 2 — Resend sandbox sender

> 1/ resend default sender is onboarding@resend.dev. it only delivers to the resend account owner. so on launch day every visitor hit a 403 on otp email. fix: verify your domain in resend, set RESEND_FROM to a verified address, redeploy. obvious in hindsight.

**Characters:** 257

### Post 3 — Stripe NEXT_PUBLIC at build time

> 2/ NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY gets baked into the bundle at build time. swap from test to live keys, redeploy — still test. you also have to uncheck "Use existing Build Cache" on that vercel redeploy or the old key sticks. lost an hour on this.

**Characters:** 252

### Post 4 — Stripe statement descriptor

> 3/ stripe statement descriptor: keep it short, recognizable, no phone number. ROADTOSF / RTSF. why no phone? a phone implies staffed support you don’t have for a hackathon. unanswered calls drive the chargeback rate up. tested by getting one.

**Characters:** 242

### Post 5 — Sonnet malformed cast tolerator

> 4/ sonnet 4.6 returns a malformed cast object roughly 1 in 30 episode generations when forced to pivot mid-arc. instead of retrying the full 5s gen, run a tolerator: try strict parse, on failure run a one-shot json-repair pass over only the cast field. ~200ms vs 5s.

**Characters:** 266
