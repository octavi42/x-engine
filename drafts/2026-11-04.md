## 5. Thread — four quiet App Store ship decisions that live in the config, not the UI

### Hook (post 1)

> shipping a voice-driven location app to the App Store is mostly things not in the UI
>
> four quiet decisions from Clio's path that lived in the config, not the screens

### Post 2 — webhook secret + CORS allowlist

> decision 1: the server tools webhook requires X-Webhook-Secret, not an API key
>
> browser origins are gated by WEB_ORIGINS. a stolen agent token no longer opens the tool surface from anywhere

### Post 3 — App Store build-config flag

> decision 2: map pins and building highlight sit behind an App Store build config, not a runtime flag
>
> review-day builds don't drag in half-finished features. product decides what ships, the build config enforces it

### Post 4 — EAS build image pinned for iOS 26 SDK

> decision 3: pin the latest EAS build image, not the default
>
> Apple rejects builds on older iOS SDKs the moment a new one lands. pinning the latest image means the submission never fails for a reason outside the codebase

### Post 5 — Step inside scenes publish out-of-band

> decision 4: Step inside scenes publish through a script, not an app release
>
> scripts/step-inside/publish.ts publishes, removes, or seeds scenes against the live API. adding a new place for a user no longer waits for App Review
